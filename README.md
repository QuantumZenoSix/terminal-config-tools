When I screenshot something with ShareX I want that that screenshot duplicated to create another image that's scaled down a bit ( < 100).
Next, I want the base64 of that scaled down image coped to the clipboard so I can paste the base64 of the scaled down image into obsidian.
Cool thing is the image is copied to my clipboard first (as the usual sharex rule) then the base64 is copied after so its the first thing i can paste (and of course i still have the image available in my clipboard)


[./sharex_rule.png](My sharex rule)

If you ever want to revert this (conver the base64 in your vault into actual images), there's an obsidian plugin to convert encoded images back into files and link to them: obsidian://show-plugin?id=convert-base64-to-png
