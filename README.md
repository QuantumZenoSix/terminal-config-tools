# Terminal Tools

A collection of command-line utilities, terminal enhancements, and developer productivity tools for a better day-to-day workflow.

This repository brings together useful tools, scripts, and configurations for working in the terminal. Projects are organized by category, making it easier to find practical utilities, improve existing workflows, and fill gaps in the standard Unix toolset.

## Categories

| Directory | Description |
| --- | --- |
| [backup-and-security](./backup-and-security/) | Tools and utilities for backups and security-related tasks. |
| [customization-tools](./customization-tools/) | Terminal and development environment customization. |
| [git-tools](./git-tools/) | Utilities for working with Git and streamlining version control workflows. |
| [image-video-tools](./image-video-tools/) | Command-line tools for working with images and video. |
| [shell-tools](./shell-tools/) | Shell scripts, command-line utilities, and workflow improvements. |
| [unix-missing-core-utils](./unix-missing-core-utils/) | Utilities that provide functionality missing from, or useful additions to, standard Unix command-line tools. |

## Getting Started

Clone the repository:

```bash
git clone https://github.com/QuantumZenoSix/terminal-tools.git
cd terminal-tools
```

Browse the category directories to find a tool that fits your needs. Each project may have its own dependencies, installation steps, and usage instructions, so check its documentation before using it.


Suggestions, improvements, and additional tools are welcome.
